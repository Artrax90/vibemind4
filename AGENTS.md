# VibeMind — Project Rules & Knowledge Base

## UI / UX Conventions

### Markdown Preview & Code Blocks
- **Кнопка копирования кода:**
  - В блоках кода в режиме предпросмотра (markdown preview) в правом верхнем углу **всегда отображается** кнопка копирования («Копировать» / иконка `Copy`).
  - **Бейджи с названием языка не отображаются.**
  - При клике код копируется в буфер обмена (`navigator.clipboard` с fallback через `textarea` / `execCommand`).
  - При успешном копировании кнопка на 2 секунды меняется на зелёную галочку с надписью «Скопировано!».
  - Поведение единообразно поддерживается как для блоков с подсветкой синтаксиса (`SyntaxHighlighter`), так и для простого текста без языка.
  - Изменения в кодовых блоках и превью всегда синхронизируются между веб/мобильной версией (`src/components/Editor.tsx`) и десктопной версией (`src/desktop/Editor.tsx`).

## Environment & Tooling (Windows)

- **Node.js / npm / npx:**
  - Расположение: `$env:LOCALAPPDATA\Programs\nodejs`
  - Для запуска команд сборки и линтинга добавлять путь в PATH:
    `$env:PATH = "$env:LOCALAPPDATA\Programs\nodejs;$env:PATH"`
- **Git:**
  - Расположение: `$env:LOCALAPPDATA\Programs\git\cmd\git.exe`
  - **Proxy Gotcha:** При операциях с удалённым репозиторием GitHub (push/fetch) локальный IDE-прокси `127.0.0.1:59115` может отдавать ошибку `407 Proxy Authentication Required`. Для обхода использовать:
    `git -c http.proxy="" -c https.proxy="" push origin main`

## Telegram Bot & Reminders

- **Голосовые команды (STT) и парсер напоминаний:**
  - Обработка опечаток транскрибации STT (например, «напомнив» -> «напомни в», «в 0.16», «в 1.08» не должны определяться как даты месяцев).
  - Поддержка числительных словами («через две минуты», «через полчаса») и склонений дней недели («в эту пятницу»).
  - Поиск и сопоставление заметок по голосовым запросам («добавь в заметку сериалы ...») нормализует окончания и падежи.
